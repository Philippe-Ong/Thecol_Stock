# Gestion Stock Thé Froid

Application de gestion du stock de thé froid avec 5 arômes et 3 formats.

## Déployé

**URL :** https://philippe-ong.github.io/Thecol_Stock/

## Fonctionnalités

- Gestion des lots par arôme, format et date de production
- Suivi des dates limites de vente (DLV) et de consommation (DLC)
- Stock vendable (< 1 mois)
- Historique de production
- Paramètres configurables (arômes, formats)
- Modifier et supprimer des lots

## Développé localement

```bash
npm run dev
```

Ouvrez [http://localhost:3000](http://localhost:3000) pour voir l'application.

## Déployer sur GitHub Pages

Le déploiement se fait automatiquement via GitHub Actions à chaque push sur la branche master.
